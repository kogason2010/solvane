# Solvane

A cinematic analytical-chemistry website for **Solvane**, a fictional company. It is a design study built with React, Three.js, GSAP and Lenis.

**Live site:** https://kogason2010.github.io/solvane/

- The repository root holds the built, static website that GitHub Pages serves.
- `source/` holds the full project source. See `source/README.md` for how to develop and rebuild it:
  - `npm install`
  - `npm run build`
  - copy the contents of `dist/` to the repository root
